## FAQ

### What is XCutors?

XCutors is a curated Windows desktop package that bundles several popular Roblox script executors—Volt, Synapse Z, Potassium, and Wave—alongside a universal loader called xcutorsLoader for convenient management.

### Is XCutors free to use?

Yes. The loader and all included executors are distributed free of charge through this repository.

### Which Windows versions are supported?

XCutors requires Windows 10 (build 1903 or later) or Windows 11. Both x86 and x64 architectures are supported.

### Why does my anticomponent flag the files?

Script executors inject code into external processes, which heuristic engines often classify as suspicious. You may need to add an exclusion folder in your anticomponent settings. Always download from this official repository to ensure file integrity.

### How do I update the executors?

Open xcutorsLoader, navigate to the executor tab, and click 'Check for Updates'. The loader will download and apply the latest version automatically.

### Can I use my own Lua scripts?

Absolutely. You can paste scripts into the built-in editor, drag and drop .lua files, or load scripts from the integrated script hub.

### Which executor should I choose?

Each executor has different strengths. Volt is known for speed, Synapse Z for broad script compatibility, Potassium for stability, and Wave for its modern UI. Try each one and see which fits your workflow best.

### Does this work on Mac or Linux?

No. XCutors and all included executors are built exclusively for Windows. There are no plans for cross-platform support at this time.

### Where can I report bugs or request features?

Open an issue on this GitHub repository using the provided templates. The community and maintainers actively review and respond to reports.
